# Runtime dependencies - Testinium-QA (Python 3.14 port)

# This file is the one authoritative runtime dependency list. pyproject.toml

# and setuptools reads the requirement lines below at build time - comment and
# blank lines stripped - so the installed metadata and what
# `pip install -r requirements.txt` installs cannot drift apart. Editing a pin
# here is therefore the whole of the change; nothing has to be mirrored.
#
# Test-only pins live in requirements-test.txt, a separate list that this file
# neither chains nor repeats. There is no lockfile, no hash regime, no
# constraints file and no environment marker: the exact pins below are the
# entire declaration.
