{#- --------------------------------------------------------------------------- partials/step_row.html - one step of a scenario or a background, with its detail. --------------------------------------------------------------------------- One of the three shared partials, rendered into all three surfaces: the single self-contained artifact page, the generated report tree and the HTTP views. It composes the other two rather than restating them - badge markup comes from partials/status_badge.html, screenshot markup from partials/lightbox.html. API - imported without the calling context, so every value arrives as an argument: {% from 'partials/step_row.html' import step_row, step_keyword %} step_keyword(step) answers the keyword as text, trimmed, and emits no markup. The model carries it with the trailing space of the reference formatter - "Given ", "And " - and this is the one place that space is removed. It is a macro because the pretty templates need the same token to build the generated tree's per-keyword class. A step that is not a mapping answers the empty string. step_row(step, uid=none, extra_classes={}, filterable=true, duration_fallback=none, inline_args=false, show_location=false, embeddings=none, screenshot_fallback_caption=none) renders one step, and the EMPTY STRING when step is not a mapping. An EMPTY mapping does render - no keyword, no name, an unknown status - because dropping a step would misreport the run. uid distinguishes this row's detail id; see determinism below. extra_classes carries class tokens per slot - step keyword name badge duration detail error args arg - or a plain string for the step container alone. A missing, blank or non-string slot means none, and slots.badge set to boolean false, tested by identity, is the one sentinel in this file: it suppresses the badge. filterable=true puts the status-filter hooks on this row; a caller whose scenario container is already the filter unit passes false, because hiding an element hides its whole subtree. duration_fallback is what renders when no usable duration arrives; its default renders no duration element at all. inline_args splices the matched arguments into the name at their recorded offsets rather than listing them in the detail region, falling back to the list when an offset does not fit the name exactly. show_location renders the resolved step location in the detail region. embeddings are screenshot embeddings handed to the lightbox partial; they live on the SCENARIO, so the caller decides which step carries them, and screenshot_fallback_caption is forwarded as that partial's fallback caption, used only when an embedding's own name is blank. CONSTRAINTS THAT CANNOT BE READ OFF THE CODE - This macro reads ONLY step.*, never a scenario's id, tags or timestamp, which is what lets one macro serve a background and a scenario alike. A duration is a nanosecond integer and is independently optional for every status, so its presence is never inferred from one. - PAGE-WIDE UNIQUENESS OF THE DETAIL ID IS THE CALLER'S JOB. The id is derived from uid, or from the step's line when no uid is given, so a page rendering one step twice, or two features whose steps share line numbers, must pass a uid that separates them. - NO LINK DETECTION, ANYWHERE, and no URL, asset or endpoint reference of any kind. Failure text carries a literal web address of its own, and linking it would inject an external reference into the self-contained artifact FROM DATA, which no reading of this template would reveal. Escaping is automatic and nothing is declared trusted markup. - The toggle and the detail region are emitted only when the detail would have content - arguments, a location, an error or a screenshot - because a control that expands nothing is an accessibility defect. - The toggle is authored EXPANDED, aria-expanded="true", which report.js maintains from there and main.css reads for the collapsed glyph; that is the only mutable ARIA mirror this file authors, its accessible name and aria-controls relationship being static semantics. data-report-status, the conditional data-report-filterable, data-report-toggle with its aria-controls, and data-report-detail are selection hooks rather than state. None of the three runtime classes report.js writes - report-is-collapsed, report-is-filtered-out, report-lightbox-is-open - is ever server-rendered; main.css alone reads them, and their absence is the fully expanded, fully visible page. -#} {%- from 'partials/status_badge.html' import status_badge, status_token -%} {%- from 'partials/lightbox.html' import screenshots -%} {#- The keyword, normalised once for the whole project, and this macro is the project's only keyword transformation. EXACTLY THE ONE TRAILING SPACE THE SOURCE CARRIES IS REMOVED, and nothing else. A step keyword in the result model is "Given ", "When ", "Then " or "And " - the word plus a single trailing space, which the schema requires and which exists only to separate the keyword from the step name in a reconstructed line. Rendered into its own element that space is dead whitespace, so it goes; the word itself is emitted byte for byte. A blanket trim would take leading whitespace with it, which is not the same transformation: leading whitespace is not part of the schema's keyword convention, so a value carrying it is a value the model records that way, and silently rewriting it would make the rendered keyword differ from the keyword the artifact reports. Only a single trailing space is dropped, and only when there is one. Guarded with a type test rather than a truth test, because a truth test on an undefined name is what raises under a strict undefined policy - and an omitted argument is exactly how an undefined name arrives here. -#} {%- macro step_keyword(step) -%} {%- set keyword = step.get('keyword') if step is mapping else none -%} {%- set text = keyword if keyword is string else '' -%} {{- text[:-1] if text.endswith(' ') else text -}} {%- endmacro -%} {#- THE PROJECT'S DURATION PREDICATE, exported so that one reading of a duration serves every surface. A duration is usable exactly when it is a non-negative integer that is not a boolean. Each part of that answers to the model: the schema carries nanoseconds as an integer, so a float is not a duration this project produced; a negative count is not a duration at all; and Jinja's number test admits booleans, so True would otherwise arrive as the duration 1 nanosecond. Zero IS a real value - a skipped or undefined step records it - and is usable, which is why the test is not a truth test. Every aggregate over durations uses this macro rather than its own test. Without it a value this row declines to render still reached a total, so a page could show a step with no duration inside a feature whose total had counted it. -#} {%- macro duration_is_usable(value) -%} {{- 'yes' if (value is integer and value is not boolean and value >= 0) else '' -}} {%- endmacro -%} {#- One step, with its detail.
