Nothing to show here

Every page in this viewer is a view of a report artifact that a completed test run left behind. Where there is no such view to render, this page stands in its place — in the same words every time, whatever the reason, because the reason is not this viewer's to report.

Runs start from the command line, with run-tests. The project documentation covers that command; this viewer only reads what a run has already written, and starts nothing itself.

From here, open the artifact index, which loads whether or not a run has happened yet, says which report artifacts are on disk, and links each one that is.
