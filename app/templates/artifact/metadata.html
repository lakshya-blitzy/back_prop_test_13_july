Both are read straight from the normalised result model. This template computes nothing: it counts nothing, derives no status, formats no timestamp and holds no path literal. API {% from "artifact/metadata.html" import metadata_block %} {{ metadata_block(metadata, summary) }} metadata_block(metadata, summary, extra_classes='') metadata is a mapping of implementation{name,version}, runtime{name,version}, os{name} and cpu{name} plus the run-level timestamps generated_at and started_at, in the model's own format. summary is a mapping of the count groups features, scenarios and steps - each a mapping of status to count, or a bare number read as that group's total - plus the earliest scenario start as started_at, for which start_timestamp is accepted as a spelling. extra_classes appends class tokens to the single root element, runs of whitespace collapsed. Both mappings are optional in every part: a missing argument, a null, a non-mapping, a sparse mapping, a blank value or a count that is not a number renders as though that item were absent. So this file cannot raise under the strict undefined policy the tests enable and cannot print the word None into a report, and a run that selected no scenario renders as a deliberate empty state rather than as a gap. CONSTRAINTS THAT CANNOT BE READ OFF THE CODE - Status is never decided here: every value reaching a data-report-status attribute goes through the badge partial's normaliser first, and that partial's status_badge macro is deliberately not called, because a tqa-count is itself a status-coloured container and a badge inside one would state the same status twice. - Counts are presented in the badge partial's reading order with any unrecognised key after them in case-sensitively sorted position, so two keys differing only in case cannot fall back on insertion order and identical input yields identical structure. - Colour never carries meaning alone: every count states its group and its status in words, and an unrecognised key keeps its own spelling and gains the state it folded to in parentheses when the two differ. - Two markup choices follow the stylesheet rather than convention: the provenance grid is a list rather than a description list, because tqa-meta-item is a flex container and generates no marker where a dd would keep a browser margin nothing here resets; and a count sits in a b element, which that stylesheet sizes inside tqa-count and gives tabular figures, so adjacent digits line up. - Timestamps are emitted exactly as the model carries them, as both the machine-readable value and the text of a time element. Nothing is re-parsed, reformatted or localised, and no date library is reachable. - Inlined into a page that must open from a filesystem with no network, so no URL of any form, no stylesheet, script, image, font or sibling-page reference, no endpoint-builder call and no icon glyph.
